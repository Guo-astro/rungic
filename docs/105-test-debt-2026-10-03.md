# 测试欠账清理（2026-10-03）

功能清单（`quality/`，规则见 quality/README.md）建立时，有 251 条 Linux 体验只在手机上或靠人工检查（device-only）、120 条体验没有任何检查（untested）、16 个安卓接口里有 24 个侧面没有契约测试（one-sided-contract）。这一轮把它们分给 6 个并行的子任务（Agent、应用、桌面、桌面模式、交付与安装、接口契约），各在自己的 git worktree 里补测试，由主会话复核、合并。全程没有碰手机；接口提供方的只读检查由主会话在 G100 S 上运行。

## 结果

| | 开始 | 结束 |
|---|---|---|
| device-only | 251 | 44 |
| untested | 120 | 0 |
| one-sided-contract | 24 | 0 |

- 新增离线测试与系统测试（`tools/system/tests/`，Mac mini 上的无头 KWin 和一次性容器）；每个测试按 `covers:` 声明它检查的体验。
- 只有手机能说明的体验写了 `device: 原因`（性能、帧率、时序、Android 路由与硬件），仍要有实机或人工检查；暂时无法检查的写 `gap: 原因`；接口一侧暂时测不了的写 `gaps:`（`kwin-android-host`、`host-input`、`gpu-device` 的使用方：需要 KGSL 和安卓宿主合成器）。
- 13 个接口的提供方只读检查（`contract.*`，release/acceptance.json）在 G100 S 上全部通过，共 31 个查询。检查只发送契约里标为 `read_only` 的查询，隐私字段（剪贴板文字、号码、名字）在手机上清空后才传回。

## 剩下的 44 条 device-only

几乎都因为系统测试镜像装的是 Ubuntu 原版组件，而这些体验在本项目打过补丁的组件里：plasma-mobile（外接屏、面板、外壳）、KWin、kscreen（显示大小）、plasma-settings、plasma-keyboard、剪贴板历史、xdg-desktop-portal-kde（文件对话框、录屏共享）、Qt Multimedia、libcamera、polkit-kde-agent-1；另有 Discover/Flatpak/Docker 需要 systemd、logind 与 polkit。测原版不能算测我们的补丁。下一步：让系统测试镜像从发布仓库装上本项目重建的包（或在镜像里按补丁队列构建），再把这些体验改为系统测试。

## 发现并修复的产品缺陷（每个都带修复前失败、修复后通过的测试）

- Agent：API Key 目录权限是 0755 而不是 700；用量小组件点 Agent 标志不再回到对话（E7）；`ui_apps`、`ui_find` 会打开无障碍却标为只读；浮层不跟随应用改过的主题；用户没有 `~/.config/kdeglobals` 时，Agent 工作区第二次启动失败。
- 桌面模式：独立桌面的 plasmashell 和剪贴板桥第一次出错退出后就再也不重启（`set -e` 结束了循环）；磁贴不显示“全屏”；出错只显示“出了点问题”；应用被冻结时开关第一次请求要等 5 秒（体验要求 1 秒内）。
- 应用：语音消息没有路由到 Linux 麦克风时，聊天应用的录音没有取消，可能把真实麦克风的声音发出去（docs/62 的要求）。
- 桌面：Rime 在敏感输入框里其实仍在学习词频（`_no_learning` 在 librime 1.16.1 不存在，改为访客会话）；移动数据改 APN 返回成功但什么也没改（改为 NotSupported）；设备面板连不上安卓时显示旧数据和原始错误；底部选择面板打开时返回手势无效。
- 交付与安装：离线测试的防护只拦了 `_run`，`rungic_device.run()` 仍会先调用真实的 adb；包改名时管理员停用的单元被重新启用；设备预检读取了活动槽位却没有核对；录制追踪后 KWin 的追踪标记没有恢复；输入探针的“含中文”判断因多余的转义永远不对；`rungic-a11y` 不显示元素文字；全新检出时崩溃符号化缺目录。
- 合并后由主会话修复：关闭“朗读回答”后，点单条回答的“朗读”没有声音（`play()` 丢掉了所有音频，现在朗读进行中照常播放）；`rungic-cua` 补上对 `python3-pypinyin` 的依赖声明（此前靠 `rungic-voice-agent` 间接装上）。
- 测试本身：`test_call_cards.py` 的定时器在测试结束后存活，较慢的后续测试会段错误。

## 记录了、未修的问题

- 安卓音频断开期间，默认输出会切到无声的 Linux 扬声器，与“它们不会成为默认”的体验不符；断开期间声音该去哪里需要产品决定。
- 按住说话类语音消息：松手即发送，取消录音的方法因应用而异，仍可能发出几秒真实麦克风声音。
- PageStack 把 Back 键注册了两次，Back 键因此无效（手机不发这个键，见 docs/102）。
- 部分覆盖：design-system/E1 应用固定主题重启后保留、panels/E1 应用工作区从状态栏下沿开始、host-bridges/E3 平台 socket 只接受 UID 0/1000，这些部分没有检查。

## 过程中的教训

- worktree 隔离默认从 main 建，而工作在功能分支上：子任务开工前要先把 worktree 快进到当前分支。
- 多个子任务同时在 Mac mini 上跑系统测试，会因编译占满内存而失败，清理旧源码树时还会删掉别人正在用的；`tools/system_test.py` 现在加了锁，一次只跑一个，按时间清理。
- 一个子任务调试时私有 D-Bus 的 socket 路径过长，测试服务短暂连到了 K8 上用户自己的会话总线、占了 `org.kde.Solid.PowerManagement` 等名字，随后自行退出；现在测试强制使用短路径的私有总线。
- 两个子任务各自改了同一个测试替身的接口（`StandIn.answer` 的返回值），合并后有 6 个测试失败，在合并提交后修复。共享测试基础设施的改动要小、要向后兼容。
